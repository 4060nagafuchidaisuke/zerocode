# 完成チェック

次の6つの手順を、番号つきでそのまま学習者に示す。動かなかった番号を聞いたら、関係するファイルを読んで、原因の見立てを2行で伝える。ファイルは変えない。

1. アドレスの /rooms から後ろを /enter に変えて開き（入室画面が出ていたらそのまま）、「ゆい」で入室する。ルームの一覧が出て、右上に名前が出る
2. 「おしゃべり」を開き、会話を下までスクロールする。自分の吹き出しは右、ほかの人の吹き出しは左で頭文字の丸が付き、名前のとなりに時刻がある
3. 「通しで確かめています」と送る。送ると画面が上に戻るので、下までスクロールする。いちばん下に自分の吹き出しが増えている
4. その吹き出しを「編集」で「書き直しも動きました」に書き直す。「おしゃべり」に戻り、文が変わっている
5. 同じ吹き出しを「削除」する。その1件だけが消える
6. アドレスをコピーして新しいタブで開き、そちらから「もう1つのタブから送りました」と送る。先に開いていたタブで5秒ほど待って下までスクロールすると、いちばん下に増えている
